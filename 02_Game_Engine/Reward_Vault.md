# 🎁 Reward Vault — Self-Reward System

> กลับ [[000_Index]] | ดูด้วย [[RPG_Mechanics]] | [[Boss_Shadow_Sloth]]

---

## 🧠 ปรัชญาของ Vault (ดร.นัท)

> *"Willpower เป็นของมีจำกัด — แต่ระบบที่ดีทำให้ทำพฤติกรรมดีโดยไม่ต้องใช้ Willpower"*

Self-Reward Vault ทำงานตามหลัก **Operant Conditioning** — การให้รางวัลตัวเองอย่างมีระบบหลังจากทำพฤติกรรมดี ทำให้สมองเชื่อมโยง "ทำกิจกรรม = ได้ของที่ชอบ" และสร้าง Habit Loop ที่แข็งแกร่ง

**กฎสำคัญ:** ของที่อยากได้ต้องมาจาก Vault เท่านั้น — ห้ามเอา Free!

| ไอคอน | รางวัล | Gold | คำอธิบาย |

## 🎯 การออกแบบ Gold Economy

### เวลาที่ต้องใช้ในการ Unlock รางวัล (ประมาณ)

```
🎬 ดูหนัง (25 Gold):
→ ทำกิจกรรมเล็กๆ 5-8 ครั้ง ≈ 1-2 วัน

🎮 เล่นเกม (30 Gold):
→ ทำกิจกรรมปกติ ≈ 2-3 วัน

😴 นอนดึก (40 Gold):
→ สัปดาห์ละครั้งได้สบาย

🍜 Cheat Meal (50 Gold):
→ ทำกิจกรรมต่อเนื่อง ≈ 4-5 วัน

🏖️ Day Off (150 Gold):
→ ทำดีตลอดสัปดาห์ถึงจะมีเหลือ ≈ 2-3 สัปดาห์

🛒 Wishlist (200 Gold):
→ เซฟนาน ≈ 3-4 สัปดาห์ ของต้องคุ้มจริงๆ
```

## 📝 Custom Rewards (เพิ่มเองได้)

ถ้าอยากเพิ่มรางวัลในแอป — แก้ไฟล์ `index.html` ที่ส่วน `VAULT` array:

```javascript
const VAULT = [
  // เพิ่มรายการใหม่ตรงนี้:
  { icon:'🍕', name:'กิน Pizza', cost: 45, desc:'Pizza หน้าที่ชอบ 1 ถาด' },
  { icon:'🎵', name:'Concert/Show', cost: 300, desc:'ดูคอนเสิร์ตที่อยากไป' },
  // ...
];
```
