## 🧠 ทำไมต้องทำ? (ดร.นัท อธิบาย)

- **Neuroplasticity:** สมาธิเปลี่ยนโครงสร้างสมองได้ภายใน 8 สัปดาห์
- **Prefrontal Cortex:** การนั่งสมาธิกระตุ้น PFC — ส่วนที่ควบคุมการตัดสินใจ
- **Stress Reduction:** ลด Cortisol ลง 20-30% ในคนที่ฝึกต่อเนื่อง
- **Focus:** เพิ่มช่วงสมาธิ (attention span) โดยตรง

## 📋 Protocol แนะนำ

### Beginner (Lv. 1-3)
```
☐ เริ่มที่ 5-10 นาที/วัน
☐ ใช้ App ช่วย เช่น Insight Timer, Headspace
☐ เน้น Breathing — หายใจเข้า 4, ค้าง 7, ออก 8
```

### Intermediate (Lv. 4-7)
```
☐ 15-20 นาที/วัน ไม่มี App
☐ เพิ่ม Body Scan สัปดาห์ละ 2-3 ครั้ง
☐ ลอง Walking Meditation ตอนเช้า
```

### Advanced (Lv. 8+)
```
☐ 30+ นาที/วัน สม่ำเสมอ
☐ ศึกษา Vipassana หรือ Zen
☐ ทำ Mini Session 3-5 นาที ระหว่างวัน
```
