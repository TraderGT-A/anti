## 🧠 ทำไมต้องทำ? (ดร.นัท อธิบาย)

- **BDNF (Brain-Derived Neurotrophic Factor):** การวิ่งกระตุ้น BDNF — "ปุ๋ยของสมอง" ช่วยความจำและ Learning
- **Endorphins:** Runner's High เป็นของจริง — ลด Anxiety ได้เทียบเท่ายา
- **VO2 Max:** เพิ่ม VO2 Max = Longevity marker ที่ทรงพลังที่สุดที่วัดได้
- **Mental Toughness:** ทุกครั้งที่อยากหยุดแต่ไม่หยุด = เพิ่ม Willpower bank

## 📋 Program แนะนำ

### Beginner — Couch to 5K (9 สัปดาห์)
```
สัปดาห์ 1: วิ่ง 1 นาที / เดิน 1.5 นาที × 8 รอบ
สัปดาห์ 3: วิ่ง 3 นาที / เดิน 1.5 นาที × 5 รอบ
สัปดาห์ 5: วิ่ง 20 นาที ต่อเนื่อง
สัปดาห์ 9: วิ่ง 30 นาที / 5 กม. ได้แล้ว!
```

### Running Zones (ตาม Heart Rate)
```
Zone 1 (50-60% Max HR): Recovery, เดินเร็ว
Zone 2 (60-70% Max HR): ⭐ Base Building — สำคัญที่สุด
Zone 3 (70-80% Max HR): Tempo Run
Zone 4 (80-90% Max HR): Threshold
Zone 5 (90-100% Max HR): Sprint / VO2 Max
```

> [!TIP] 80% ของ Mileage ควรอยู่ใน Zone 2 — วิ่งช้าๆ เยอะๆ ก่อน

### Weekly Structure
```
จ: Rest หรือ Walk
อ: Easy Run (Zone 2) 30-40 นาที
พ: Strength Training
พฤ: Easy Run (Zone 2) 30 นาที
ศ: Rest
ส: Long Run (Zone 2) 45-60 นาที
อา: Rest หรือ Recovery Walk
```
