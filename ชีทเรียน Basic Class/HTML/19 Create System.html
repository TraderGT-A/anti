Z · Zone

ช่วงราคาที่ได้เปรียบในการเข้า

ออกแบบระบบฉบับของตัวเอง

  1. ปัญหาในการเทรดของฉัน 3 ข้อคืออะไร
  2. จริตของฉัน: ถือนานแค่ไหน ทนคืนกำไรและ Drawdown ได้เท่าไร

  4. T, Z, C ของฉันใช้เครื่องมืออะไร
  5. จุดอ่อนของระบบคืออะไร และจะแก้ที่ตัวเองอย่างไร (ไม่ Curve Fit)
