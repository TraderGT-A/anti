# แหล่งข้อมูล (Source Notes รวม)
> แยกข้อเท็จจริงออกจากการตีความ · กลับไป [[000_Quant_Index]] · เทมเพลตจาก repo QuantCorner (Source Note)

## 1) TradingView scanner (หน้าเว็บ + cron)
- ใช้ทำ: อันดับ RS, Scanner, ผู้นำรายเดือน, Gate, EPS log · ปลายทาง `https://scanner.tradingview.com/{thailand|america}/scan`
- ฟิลด์ที่ใช้: ราคา/ผลตอบแทน (Perf.*), SMA50/150/200, EMA20, high/low 52 สัปดาห์, ATR, ปริมาณ/มูลค่าซื้อขาย, EPS ttm และ growth, กำไรสุทธิ ttm และ growth, วันประกาศงบ
- ข้อจำกัด: **ไม่ใช่ข้อมูลทางการ**, ค่าอาจถูกแก้ย้อนหลัง, ไม่มีหุ้นที่ถูกเพิกถอน, สถานะ "ปัจจุบัน" เท่านั้น (ไม่ย้อนหลัง) · ใช้สำหรับ backtest ไม่ได้ ต้องสะสมเอง
- บันทึก point-in-time: Supabase `fund|th|latest` และ `fund|th|log|YYYY-MM` (เก็บเฉพาะวันที่ค่าเปลี่ยน) เริ่มเก็บ 2026-10-10 ([[Forward Test ผู้นำไทย]])

## 2) Yahoo Finance chart API (รายวัน)
- ใช้ทำ: backtest หุ้นรายตัว/ดัชนี ตั้งแต่ ~2005 (US 2000+ บางชุด) · เก็บนอก git ที่ `%LOCALAPPDATA%\hermes\scripts\{us11,us_old,idx_long,em}\`
- ข้อจำกัด: พูลหุ้น EM/ไทยเลือกตามมูลค่าซื้อขาย **ตอนดึง** → มี survivorship/selection bias; ราคาแบบเดียวไม่รวมปันผลทุกกรณี; ไม่รวม FX; ตลาดที่รหัสไม่ตรง Yahoo (Malaysia) ดึงไม่ได้ → ตัดออก
- ผลกระทบ: ผลไทย/EM ทั้งหมดต้องอ่านเป็น "อาจเกินจริง" จนกว่าจะมีข้อมูล delisted

## 3) FRED DTB3 (T-Bill 3 เดือน)
- ใช้ทำ: ดอกเบี้ยเงินสดใน backtest US · ไฟล์ `tbill_long.csv`

## 4) ดัชนีอ้างอิง
- SET (Gate ไทย), S&P 500 / RSP total return (ตัวเทียบ US) · Gate = ดัชนี เทียบ SMA50/SMA200

## 5) Supabase `snapshots`
- ตารางเดียวเก็บ: snapshot รายวัน, `leaders|state` (paper-trade), `fund|th|*` (EPS), `dlog|*` (Decision Log)
- ข้อมูลเก่าที่ผิด: แถววันเสาร์/อาทิตย์ปนอยู่ (ผู้ใช้ต้องรัน SQL ลบเอง — ยังค้าง)

## 6) ยังไม่มี
- Webull OpenAPI (ยังไม่ทราบว่าบัญชีมีสิทธิ์ไหม; ถ้าได้ key ให้เก็บใน `%LOCALAPPDATA%\hermes\secrets\` ห้ามใส่ใน repo)
- ข้อมูลหุ้นที่ถูกเพิกถอนของไทย/EM
