## 3) UX ที่ปรับเพิ่ม (เหตุผล "ใช้ดี")

1. **ตัวอักษรเล็กสุดขยับขึ้นหนึ่งขั้น** — `text-[8px]→11px`, `[9px]→12px`, `[10px]→13px`, `[11px]→13px`, `[12px]→14px`, `[13px]→15px` (ตรงกับที่บอสเคยสั่งให้ขยายตัวอักษร)
2. **เป้าแตะ (touch target)** — chip/ปุ่มสูงขั้นต่ำ 32px, ช่องกรอก/ดรอปดาวน์ 40px
3. **ตัวเลขใช้ Space Mono + ป้ายตัวพิมพ์ใหญ่ + tracking** → อ่านตัวเลขเร็วขึ้น (ภาษาไทยไม่ได้รับผลจาก uppercase)
4. **ลำดับชั้นด้วยความหนาขอบ** — การ์ด 3px, hover 5px (แทนเงา), เส้นใต้หัวตาราง 3px, เส้นคั่นแถว 1px
5. **คอนทราสต์สำหรับผู้ใช้จริง** — ราคาขึ้นเขียวล้วน/ลงแดงล้วนบนพื้นขาว, ป้ายตลาดดำทึบ, tooltip ดำ-ขาว
6. **มี focus ring 3px + เคารพ `prefers-reduced-motion`** (พื้นคุณภาพขั้นต่ำ)
7. **ข้อความอธิบาย (ⓘ / tipbox)** ยังอยู่ครบ — ไม่ตัดข้อมูลออก (กฎ "แก้ 1 หาย 2")

**จุดที่จงใจ "เด่น" ที่เดียว (restraint)**: หัวเรื่อง `RS Dashboard` เป็น Archivo Black ตัวใหญ่ + เส้นดำ 5px — ที่เหลือเงียบและเป็นระบบ

## 4) สิ่งที่ "ไม่แตะ" (สำคัญสุด)

- ไม่แก้ `fetch`, `/api/*`, สูตร RS, การกรอง, การจัดกลุ่ม, sort, ตัวเลขใด ๆ
- ไม่แก้ id/ฟังก์ชันที่ปุ่มเรียก (ห้ามแก้ 1 เสีย 1)
- งานนี้เป็น **UI layer** ล้วน: CSS override + สีกราฟใน JS เท่านั้น

## 5) วิธีพิสูจน์ว่าไม่พัง (ตามกฎบอส: verify by running)

1. `node` render-sim (stub DOM) รัน `index.html` เดิม **กับ** `index_rawblock.html` → ดึง "ลายนิ้วมือข้อมูล" (จำนวนหุ้น, Top5 RS/ราคา/change, breadth, money flow, ลำดับตาราง) มาเทียบ → **ต้องเท่ากันเป๊ะทุกค่า**
2. compile JS ด้วย `new Function(js)` (ไม่ใช้ `node --check` เพราะโค้ดมี function ซ้ำแบบเดิม)
3. เปิด preview ในเบราว์เซอร์จริง (proxy `/api/*` ไป live) แล้วแคปภาพให้ดู
4. ยัง **ไม่ deploy ขึ้นเว็บจริง** — รอบอส/GT ดูแล้วอนุมัติก่อน

## 7) รอบ 2 (ตามที่ GT สั่ง 5 ต.ค.) — โหมดมืด + เต็มจอ

**ก. โหมดสว่าง/มืด (ปุ่ม 🌙 มืด / ☀️ สว่าง ในแถวบน)**
- เขียนชั้นธีมใหม่ให้ใช้ CSS variable (`--rb-bg/fg/fg2/fg3/line/sunken/hover/inv-bg/inv-fg`) แล้วสลับด้วยคลาส `rb-dark` ที่ `<html>` → **โครงเดิมไม่ต้องเขียนซ้ำ**
- โหมดมืด = กลับด้านทั้งระบบ (พื้นดำ ตัวอักษรขาว ขอบขาว ปุ่ม active กลายเป็นขาว-ดำ) + **เร่งสีข้อมูลให้อ่านบนพื้นดำ**: เขียว `#00D65C` · แดง `#FF5147` · น้ำเงิน `#7C9BFF` · ส้ม `#FFC24D`
- จำค่าใน `localStorage` (เปิดหน้าใหม่ได้ธีมเดิม) + กราฟ LightweightCharts เปลี่ยนสีตามธีม (patch `createChart` + series)
- ปุ่มสลับจะ redraw หน้าทั้งหมด เพราะกราฟถูกวาดด้วยสี ณ ตอนสร้าง

**ข. เต็มจอ เต็มสัดส่วน**
- ตัด `max-w-7xl` (เต็มความกว้างจอ), ลด padding/margin/gap ระหว่างบล็อกเหลือ 6–8px, การ์ดเริ่มต้น 3 คอลัมน์
- ผลข้างเคียงที่แก้ให้: ลดช่องว่างขวาของแผง + แถบ index 4 ใบเต็มแถว

**ค. บั๊กที่เจอและซ่อมระหว่างทำ (ของเดิม ไม่ใช่ของใหม่)**
- **กราฟ Breadth History ไม่เต็มกล่อง**: สร้างด้วย `el.clientWidth||320` ตอนกล่องยังกว้าง 0 → กราฟเล็กค้าง 254px ในกล่อง 1013px → เพิ่มการวาดใหม่เมื่อตรวจพบว่ากราฟแคบกว่ากล่อง (จาก 254 → **946/1013px**) + redraw เมื่อ resize
- **คอนทราสต์โหมดมืด**: ปุ่ม "♻️ แคช" กลายเป็นดำ-บน-ดำ (คลาสพื้นกลับสี แต่ตัวอักษรถูกบังคับเป็น inv-fg) → แก้ให้ตัวอักษรตาม `--rb-fg` · ตรวจด้วยสคริปต์ไล่ contrast ทุก element (ไม่ใช่ดูด้วยตา)
