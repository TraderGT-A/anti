# งานประจำวัน: เช็กว่าหุ้นไทยยื่นงบแล้วหรือยัง จากหน้าข่าว SET (สำหรับ Antigravity)

**เป้าหมาย** วันประกาศงบในเว็บ rsdash มาจาก TradingView ซึ่งบางตัวคลาด 1 วัน (เช่น PSL ยื่นงบ 2 พ.ย. 17:51 แต่เว็บขึ้น "งบพรุ่งนี้") งานนี้คือไปอ่าน "ข่าวงบการเงิน" ที่ SET เผยแพร่จริง แล้วบันทึกเป็นไฟล์เล็ก ๆ ให้เว็บใช้ยืนยัน

**ทำวันละกี่ครั้ง** วันละ 1 ครั้ง เวลา **17:20 น.** (ก่อน Hermes deploy รอบ 17:40) — ถ้าต้องการเพิ่มค่อยเพิ่มรอบเที่ยงครึ่ง (12:50) ภายหลัง ไม่ต้องทำพร้อมกัน

## ขั้นตอน (ทำเหมือนคนใช้เว็บ ใช้เบราว์เซอร์ ห้ามเรียก API ของ SET ตรง ๆ ห้ามปลอมเบราว์เซอร์/คุกกี้/โทเค็น)
1. เปิด https://www.set.or.th/th/market/news-and-alert/news ด้วยเบราว์เซอร์ปกติ
2. ตัวกรอง: ประเภทหลักทรัพย์ = **หุ้น** · ระยะเวลา = **5D** (หรือ "ข่าววันนี้" ถ้ารันทุกวันและไม่พลาดวัน) แล้วกดค้นหา
3. ดูกลุ่ม **"ข่าวงบการเงิน"** (รายการที่หัวข้อขึ้นต้น "งบการเงิน ไตรมาสที่ …" หรือ "งบการเงิน ประจำปี …") — เลื่อน/กดโหลดเพิ่มจนครบทุกรายการของช่วงที่เลือก
4. จดแต่ละรายการ: ชื่อย่อหุ้น · วัน-เวลาที่เผยแพร่ (เวลาไทย) · หัวข้อ
5. เขียนไฟล์ \`scripts/set_filed/raw.json\` (ทับของเดิมได้) รูปแบบ array:
   \`\`\`json
   [ { "symbol": "PSL", "datetime": "2026-11-02T17:51:40+07:00", "headline": "งบการเงิน ไตรมาสที่ 3/2569 (สอบทานแล้ว)" } ]
   \`\`\`
   - เอาเฉพาะข่าวที่หัวข้อมี "งบการเงิน" (ไม่เอา "สรุปผลการดำเนินงาน", "คำอธิบายและวิเคราะห์ของฝ่ายจัดการ", ข่าวอื่น)
   - ใส่ทุกรายการที่เห็น ไม่ต้องกรองตัวที่ไม่อยู่ในเว็บ สคริปต์จัดการเอง
6. รัน \`node scripts/set_filed/merge.mjs\` ที่โฟลเดอร์รากของโปรเจกต์ → ได้ \`rsdash/set_filed_th.json\` (รวมกับของเดิม เก็บ 60 วัน ตรวจรูปแบบให้) ดูบรรทัดสรุปจำนวน ถ้า "ข้าม" มาก แปลว่ารูปแบบ raw ผิด ให้แก้ raw.json แล้วรันซ้ำ
7. ห้ามแตะไฟล์อื่น · ห้าม commit/deploy เอง (Hermes ทำตามกติกา HANDOFF ข้อ 5.1 และ deploy รอบ 17:40)

## ถ้าทำไม่ได้
- หน้า SET เปิดไม่ได้ / โหลดไม่ครบ / ติดระบบกันบอท → **หยุดและรายงาน** ในช่อง HANDOFF.md ของ rsdash (เพิ่มรายการบนสุดของล็อก) ห้ามพยายามอ้อมระบบป้องกัน
- ไม่มีข่าวงบเลยในวันนั้น (เช่นวันหยุด) → ไม่ต้องอัปเดตไฟล์
